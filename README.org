* Sleep analysis
This script reads WHOOP export files and produces plots the following:
- Summary statistics
- Sleep duration & performance
- Sleep stages
- SWS & REM
- Bedtime & wake consistency
- Sleep debt trends
- Sleep efficiency
- Recovery & HRV
- Training load impact
- Weekly averages
